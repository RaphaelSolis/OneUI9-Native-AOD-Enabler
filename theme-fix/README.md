# One UI 9 AOD Theme Fix

Fixes Galaxy Themes AOD themes that apply but still show the default clock.

For Galaxy A16 (SM-A165F), One UI 9, firmware A165FXXUBEZJ7. Requires the [native AOD module](https://github.com/RaphaelSolis/OneUI9-Native-AOD-Enabler) and Vector or LSPosed.

## Install

1. Download `OneUI9-AOD-Theme-Fix.apk` from [Releases](https://github.com/RaphaelSolis/OneUI9-Native-AOD-Enabler/releases/tag/aod-theme-fix-v0.3) and install it.
2. Enable **OneUI 9 AOD Theme Fix** in Vector or LSPosed for **System UI** and **Always On Display**.
3. Reboot and apply your AOD theme in Galaxy Themes.

## Remove

Disable the module and reboot.
